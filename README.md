# POATPL Website

Ready Next.js website for Prasad Office Automation & Technologies Pvt. Ltd.

## Run
1. Install Node.js.
2. Open this folder in terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

`index.html` is also included as a no-build visual preview.

The supplied logo and visual assets cropped from the provided design reference are in `public/assets`.
